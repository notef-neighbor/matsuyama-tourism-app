# 松山さんぽ｜松山観光アプリ

愛媛県松山市の観光スポット・道後温泉・ご当地グルメ・イベント・モデルコース・GPSスタンプラリーをまとめた、日本語・モバイルファーストの静的Webアプリです。ビルド不要で動作します。

## 主な機能

1. **ホーム (`#/`)**
   - 松山城・道後温泉本館のシルエット装飾付きヒーローと最終確認日の表示
   - お知らせ（営業時間短縮や運行案内など）
   - 開催中・近日開催のイベント（閲覧日の日付から「開催中」「開催中（本日開催）」「まもなく」「終了」を自動判定）
   - スタンプラリー進捗カード、おすすめモデルコース、アクセス・お得なきっぷ情報
2. **スポット・イベント一覧 (`#/spots`, `#/events`)**
   - カテゴリタブ（すべて / 名所 / 温泉 / グルメ / イベント）による絞り込み
   - 名前・かな・要約によるリアルタイム検索
   - スタンプ獲得済みバッジの表示
3. **スポット詳細 (`#/spot/<id>`)**
   - 見どころ、営業時間・料金などの基本情報表、ミニ地図、Googleマップ連携リンク
   - 概算座標スポットへの注記表示
   - 関連イベント、出典リンク一覧、情報確認日、スタンプ押印ボタン
4. **地図 (`#/map`)**
   - OpenStreetMap + Leaflet による全スポット・イベント（✨ピン）表示
   - カテゴリ別フィルタチップ、ポップアップからの詳細遷移
   - 「現在地を表示」ボタン（Geolocation API）
5. **モデルコース (`#/courses`, `#/course/<id>`)**
   - 4つのテーマ別モデルコース
   - 番号付きピンと折れ線でルートを描く地図、縦型タイムライン、めぐり方のヒント
6. **GPSスタンプラリー (`#/stamp`, `#/stamp/complete`)**
   - 全15スポット対象のスタンプ台帳（進捗バー・5/10/15個マイルストーン・和風丸印デザイン）
   - 現在地とのHaversine距離計算による範囲内判定（各スポットの `stamp.radius` を使用）
   - 押印時のアニメーション演出、コンプリート達成画面（獲得日時一覧・シェア用テキストコピー）
   - 進捗はブラウザの `localStorage`（キー：`matsuyama_stamps_v1`）に保存、リセット機能付き
7. **出典一覧・アプリ情報 (`#/about`)**
   - 全スポット・イベント・お知らせ・アクセスの出典URLを一覧化

## 起動方法

ビルドツールは不要です。以下のいずれかの方法で開けます。

### 方法1: 簡易静的サーバで起動する（推奨）

```bash
cd /workspace/matsuyama-app
python3 -m http.server 8000
```

ブラウザで `http://localhost:8000/` を開いてください。

### 方法2: ファイルを直接開く

`index.html` をブラウザで直接開いても動作します（ただし位置情報機能には後述の制限があります）。

## スタンプのデモ／テストモードについて

スタンプ帳画面 (`#/stamp`) の上部にある **「🧪 デモ／テストモード」** トグルをONにすると、GPSによる距離判定をスキップしてボタン操作のみでスタンプ獲得・押印演出・コンプリート画面をテストできます。

- デモモードの状態は `localStorage`（キー：`matsuyama_stamp_demo_v1`）に保存されます。
- デモモード中は画面上部に目立つバナーが表示されます。

## データ更新方法

アプリの表示内容はすべて既存の `data.js`（`window.MATSUYAMA_DATA`）から動的に生成されます。

- 観光情報・営業時間・料金・イベントを更新する場合は、必ず各公式サイト等で最新情報を確認したうえで `data.js` の該当項目を編集してください。
- 更新時は以下もあわせて最新化してください。
  - トップレベルの `lastChecked`（最終確認日 `YYYY-MM-DD`）
  - 各スポットの `checkedAt` および `sources`（出典タイトルとURL）
  - 各イベントの `start` / `end` / `endNote` / `dates` / `sources`

## 注意事項

- **位置情報（Geolocation API）の動作条件**: ブラウザのセキュリティ仕様により、GPSによる現在地表示やスタンプの位置判定は **HTTPS** または **localhost (`http://localhost:...`)** 環境でのみ動作します。`file://` で直接開いた場合や HTTP（非localhost）では拒否されることがあります。テスト時は `python3 -m http.server` + `http://localhost:8000` またはデモモードをご利用ください。
- 地図タイル表示にはインターネット接続（OpenStreetMap および unpkg CDN からの Leaflet 読み込み）が必要です。
- 掲載している営業時間・料金・イベント日程は確認時点の情報であり、変更される場合があります。お出かけ前に必ず各公式サイトをご確認ください。

## ファイル構成

- `index.html` : アプリのエントリーポイント（ヘッダ・ボトムナビ・スクリプト読み込み）
- `css/style.css` : 愛媛みかん × 道後温泉 和モダン モバイルファーストスタイル
- `data.js` : 観光スポット・イベント・モデルコース・出典データ（既存データファイル）
- `js/utils.js` : 安全なDOM生成（XSS対策）・日付/イベント判定・Haversine距離計算・SVG装飾
- `js/map.js` : Leaflet地図制御・カスタム `divIcon` ピン・現在地表示・コース折れ線
- `js/stamp.js` : スタンプラリー状態管理・GPS判定・デモモード・押印演出・リセット確認
- `js/app.js` : ハッシュルーター・全画面レンダリング
